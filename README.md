# SafeCore-Wipro-Capstone
    A secure and fault-tolerant embedded Linux platform for reliable software updates, verification, health monitoring, and automatic rollback.

🎦**Project Overview**
    
    SafeCore is an embedded Linux software-update management system designed to make system updates safer and more reliable.
    In embedded systems, an interrupted, corrupted, or incompatible software update can leave a device in an unusable state.
    SafeCore aims to reduce this risk by introducing a controlled update process with      
    update verification, safe activation, system health monitoring, and automatic rollback.

    The project is being developed as an individual Wipro Capstone Project using C++ on Linux.

⚖️**Problem Statement**

    Traditional software updates can introduce risks such as:
        🔻Corrupted update packages
        🔻Incomplete or interrupted updates
        🔻Invalid software versions
        🔻Failed activation
        🔻System instability after an update
        🔻No reliable mechanism to return to the previous working version

    In an embedded Linux environment, such failures can be particularly serious because the device may have limited recovery options.
    SafeCore is proposed to address these problems through a structured and fault-tolerant update lifecycle.
